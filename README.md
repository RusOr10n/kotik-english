# 🐱 Котик и английский

Игра-квест для изучения английского с нуля (A0 → A1) для детей ~9 лет. Котик путешествует по 6 мирам, в каждом — уроки и босс.

## Запуск

```bash
npm install
npm run dev      # открыть http://localhost:5173 в Chrome или Safari
npm test         # тесты движка и smoke-рендер экранов
npm run build    # статическая сборка в dist/ (можно выложить на GitHub Pages / Vercel / Netlify)
```

Прогресс хранится в `localStorage` браузера: при смене браузера или устройства он не переносится сам.

`npm run build` собирает игру в **один файл** `dist/index.html`: его можно открыть двойным щелчком без сервера.

## Перенос на другой компьютер (Windows)

«Для родителей» → «🚚 Перенос на другой компьютер». Игра спросит, нужно ли сохранить прогресс, и скачает файл `kotik-english.html`: в нём вся игра и, если выбрано, прогресс. На Windows достаточно дважды щёлкнуть по файлу, и игра откроется в Edge или Chrome. Прогресс загрузится при первом запуске; если на том компьютере уже есть свой котик, игра сначала спросит, заменять ли его.

## Телефон (Android)

Вёрстка адаптивная: на узком экране карта становится вертикальной, задания перестраиваются в 2 колонки, а домик листается пальцем. На карте есть кнопка 📲 «Добавить на главный экран»: игра открывается во весь экран, как приложение, и работает без интернета.

Чтобы игра попала на телефон, выложите папку `dist` после `npm run build` на бесплатный хостинг с https. Например, перетащите папку на страницу app.netlify.com/drop. Затем откройте ссылку в Chrome на телефоне и нажмите 📲. Чтобы на телефоне был прогресс, перед выкладкой замените `dist/index.html` файлом `kotik-english.html` из переноса, переименовав его в `index.html`. Учтите, что открыть игру сможет любой, у кого есть ссылка.

## Что внутри

- **15 миров по возрастанию сложности.** 6 тематических миров (Кошкин дом → Волшебный сад → Весёлый рынок → Кошачья школа → Большой город → Остров приключений), а между ними 9 грамматических: to be, like, множественное число, a/an/the, this/that/these/those, have/has got, whose и my/your/his…, can, Present Continuous. Всего 80 уроков и 269 слов: в тематических мирах по 4–5 уроков, в грамматических — по 6.
- **Грамматика:** в каждом грамматическом мире 6 уроков. Первые четыре знакомят с новыми правилами, два последних тренируют их на уже знакомых словах. Каждый урок начинается с короткого правила с озвученными примерами. Дальше задания «выбери правильную форму» (am/is/are, don't/doesn't…), сборка фраз, а в конце мини-игра «Лопни шарик».
- **9 типов заданий:** выбрать картинку на слух, выбрать слово к картинке, мемори, собрать слово из букв, напечатать слово, собрать фразу, вставить пропущенное слово, мини-игры «Поймай рыбку» и «Лопни шарик».
- **Боссы:** битва из вопросов. За победу ребёнок получает нового котика-друга в альбом.
- **Магазин:** 40 аксессуаров, 18 окрасок котика, а также мебель и игрушки для каждой комнаты домика. Всё покупается за монетки. Вещи для закрытых комнат видны с замком: так видно, к чему стремиться.
- **Домик котика:** купленные вещи стоят в комнатах. По клику котик спит в корзинке, гоняет мячик, прячется в коробку, лезет на кошачье дерево и т. д. — и говорит, что делает, по-английски. Сначала есть только гостиная. После 5 пройденных уровней открывается ванная, после 10 — кухня, после 15 — диско-комната с диско-шаром и цветными огоньками. Каждую комнату котик называет по-английски, а о новой комнате сообщает экран победы над боссом.
- **Ежедневный бонус:** за первое задание дня даются бонусные монетки. Бонус растёт с серией дней подряд: от 10 до 40 монеток.
- **Повторение:** интервальное повторение по Лейтнеру, в нём слова с ошибками попадаются чаще.
- **Продолжение с места выхода:** незаконченный урок или повторение сохраняется после каждого шага. На карте у начатого урока появляется ⏸️, а в его карточке — кнопки «Продолжить» и «Начать заново».
- **Для родителей:** кнопка ⚙️ на карте, для входа нужно решить пример на умножение. Там статистика, свои темы, выбор голоса и скорости речи, кнопка «открыть все уровни» и сброс прогресса.
- **Свои темы:** родитель вводит или загружает файлом (.txt, .csv, .json) свой словарь. Из него автоматически получается новый уровень на карте с уроками и боссом, открытый сразу.

## Как добавить контент

Проще всего — через «Для родителей → Свои темы», прямо в игре. Чтобы добавить контент в код:

- Слова: `src/content/words.ts` (id, английский, русский, эмодзи). Эмодзи и написание должны быть уникальными, это проверяет тест.
- Уроки и миры: `src/content/worlds/*.ts`. Задания генерируются автоматически из слов и фраз урока (`src/engine/lessonBuilder.ts`).
